GoThru Street Builder

Update Report: Version 2.0.8

23 October – 6 November 2026

Feature27 Oct 2026

Implement force update for outdated app versions

  • Users on a version below the minimum supported version now see a required update dialog that cannot be dismissed.
  • The app installs the update and relaunches automatically.
  • Users on a supported version still get the regular, dismissable update notification.
  • The minimum version can be set at each release, with the dialog translated into 15 languages.
Feature6 Nov 2026

Implement fallback login (Google & email OTP) when SSO is down

  • Before opening the browser, the app checks whether the login server (SSO) is reachable.
  • If it is down, a maintenance screen offers two alternatives: Sign in with Google or a 6-digit verification code sent by email.
  • A Retry Now button switches back to SSO as soon as it recovers.
  • Users can keep working even during an SSO outage.
Fix28 Oct 2026

Fix updater version parsing and improve update dialog UI

  • More reliable version comparison, so the app correctly decides when an update is required.
  • Blurred backdrop behind the update dialog for a cleaner look.
  • Improved Windows release process.
