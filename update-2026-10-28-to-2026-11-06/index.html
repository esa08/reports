Update Report

28 October – 6 November 2026

Feature28 Oct 2026

Convert Insta360 .insp files to 360 JPG

  • Insta360 .insp files are converted to equirectangular 360 JPG directly in the app.
  • Translated into 18 languages.
Fix29 Oct 2026

Fix force update review findings

  • Updater commands are corrected, so the forced update flow behaves as expected.
  • The installing popup is updated during a forced update.
  • Menu shortcuts are disabled while a forced update is required.
Feature29 Oct 2026

Add default AI API key preference

  • Users can mark one AI API key as the default in Preferences.
  • The default key is used automatically where an AI API key is needed.
  • Translated into 18 languages.
Fix30 Oct 2026

Maximize window on Windows

  • The main window opens maximized on Windows and Linux.
  • On macOS the app keeps its fullscreen behavior.
Feature4 Nov 2026

Implement fallback login (Google & email OTP) when SSO is down

  • The app checks whether the login server (SSO) is reachable before sign-in.
  • If it is down, a maintenance screen offers two alternatives: Sign in with Google or a verification code sent by email.
  • Users can keep signing in during an SSO outage.
Performance28 Oct 2026

Speed up folder and grid thumbnail loading

  • Thumbnails of large panoramas are decoded in the background, so the UI stays responsive.
  • Decoding runs at reduced JPEG scale, which is the fastest option for large panoramas.
  • Concurrent decodes are capped at the CPU core count to avoid overload.
  • Thumbnails for a folder are pre-generated on load, so scrolling the grid is smoother.
Performance28 Oct 2026

Cap flat panorama preview source at 6144 px

  • Very large panoramas (up to 16k wide) were decoded repeatedly while dragging the flat preview, which made it stutter.
  • The flat preview source is capped at 6144 px wide. In an internal test, a 6.9-second drag dropped to about 1.7 seconds.
